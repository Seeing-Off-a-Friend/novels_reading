# 本地小说阅读器

跑在本机的小说阅读器：用 Python 标准库起一个 HTTP 服务，浏览器打开网页界面。
支持按拼音首字母归档的书库、文件夹录入、本地音乐播放、沉浸式阅读。

**零第三方依赖** —— 只用 Python 标准库（`http.server` / `json` / `re` …），
不需要 `pip install` 任何东西。

## 功能

| 能力 | 说明 |
| --- | --- |
| 书库组织 | `main/<首字母>/<书名>/<章节>.txt`，目录树按 A–Z 分组 |
| 递归扫描 | 书目录下的子目录（分卷）会被递归读取，不会漏章节 |
| 两种录入方式 | 把文件夹拖进窗口，或点工具条「导入」选文件夹 |
| 拼音首字母归档 | 中文书名自动转拼音首字母，无需第三方库 |
| 本地音乐库 | 播放 / 暂停 / 上一首 / 下一首；服务端实现了 HTTP Range，进度条能拖 |
| 沉浸式阅读 | 侧栏可收起，工具条与底栏淡出，鼠标移到边缘再显形 |
| 章节排序 | 支持「第123章」和「第一千一百一十一章」混排 |
| 编码兼容 | 章节文件 UTF-8 / GBK / GB18030 自动识别 |

## 运行

```
双击 启动阅读器.bat
```

或者命令行：

```bat
python server.py
```

浏览器会自动打开。启动脚本会自动在 PATH 里找可用的 Python，
找不到会提示怎么装 —— 也可以直接改 `server.py` 里的端口等参数。

## 目录结构

```
小说/
├── 启动阅读器.bat      双击启动
├── server.py           本地服务 + 全部后端逻辑
├── index.html          单页界面（HTML / CSS / JS 都在这一个文件里）
├── main/               小说库，首次启动自动创建
│   └── J/示例书名/第1章.txt
└── music/              音乐库，首次启动自动创建
```

`main/` 与 `music/` 属于个人内容，已列入 `.gitignore`，不进版本库。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `←` / `→` | 上一章 / 下一章 |
| `\` | 收起 / 展开目录（沉浸式阅读） |
| `Esc` | 退出沉浸式阅读 |

## 录入规则

> **文件夹名 = 书名，里面的 `.txt` 是章节，子目录原样保留。**

选中的那一层就是书，不做层级猜测。要一次导入多本，把多个文件夹一起拖进窗口。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/structure` | 完整书库树 |
| GET | `/api/chapters?book=J/剑来` | 某本书的章节列表 |
| GET | `/api/content?book=…&chapter=…` | 章节正文 |
| GET | `/api/music` | 音乐列表 |
| POST | `/api/ingest` | 录入章节（书名与相对路径走请求头，正文是裸字节） |
| POST | `/api/music/upload` | 录入音乐 |

只监听 `127.0.0.1`，不对外开放。

## 实现上的几个取舍

- **拼音首字母不引第三方库**：GB2312 的一级汉字区（3755 字）本身就按拼音排序，
  所以能用区位码反推首字母，省掉一个依赖。二级汉字区按部首排序，这套办法不适用，
  这类生僻字会归到 `#`。
- **用 `ThreadingHTTPServer` 而不是 `HTTPServer`**：浏览器打开页面会同时开好几条连接，
  单线程的 `HTTPServer` 会被其中一条占住，页面一直转圈打不开。
- **响应一律不缓存**：本地工具不需要协商缓存，留着只会出现「改了前端却看不到效果」。
- **手动补了 HTTP Range**：标准库的 `SimpleHTTPRequestHandler` 不支持，
  音频进度条拖动要靠它。
- **录入不做层级猜测**：试过「如果 `.txt` 在更深一层，就把子文件夹当成书」，
  但 `A/B/C.txt` 里 B 究竟是书还是卷，信息本身就不够，猜错反而更糟。
  可预测比聪明重要。
